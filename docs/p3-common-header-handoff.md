## ローカル実行

WASMビルドは`front`ディレクトリで行い、サーバーはリポジトリルートから起動する。

```bash
cd front
mise exec -- wasm-pack build --target web --out-dir ../server/src/assets/javascript/
cd ..
RUST_LOG=info cargo run -p server -- --env local
```

ブラウザーで `http://127.0.0.1:8080/honey_note/login.html` を開く。現在のDBは存在する。DBがない場合、設定の `sqlite://resources/db/honey_note.db` はリポジトリルート基準。既存バックアップを上書きせず、新規DBを作る際は `README.md` のDB準備手順を確認する。
